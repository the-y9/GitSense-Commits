# GitSense-Commits Viewer

For direct access to the logs and commit summaries, visit the [GitSense Commits Viewer](https://the-y9.github.io/GitSense-Commits/viewer/]).

[GitSense](https://github.com/KAMAL-02/GitSense) is a custom-built VS Code extension that automates the process of tracking my coding activity and committing those changes to a GitHub repository. The extension monitors my coding progress in one-hour intervals, generates concise summaries of my progress, and pushes them to a GitHub repository named GitSense-commits. This helps me easily track my work without needing to manually log the activities.
