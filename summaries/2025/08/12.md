# Activity Summary for 8/12/2025

## 9:12:12 PM
The project aims to predict thyroid cancer recurrence using a machine learning model deployed as a FastAPI service.  The process involved three stages: EDA, model training, and deployment.

The EDA (`eda.ipynb`) focused on data quality checks (handling missing values and duplicates), univariate analysis (count plots for categorical features and age distribution), bivariate analysis (age vs. recurrence, risk vs. recurrence, adenopathy vs. recurrence), correlation analysis (heatmaps), and class imbalance assessment. Key findings included a slightly higher recurrence rate in younger patients, a strong correlation between recurrence and high-risk categories/adenopathy, and strong correlations among T, N, M, and Stage features.  The EDA results informed feature preprocessing and model selection.

Model training (`train.ipynb`) involved a preprocessing pipeline (OneHotEncoding, StandardScaler, SimpleImputer), model experimentation (Logistic Regression, Random Forest, XGBoost/LightGBM, SVM), and model evaluation (Accuracy, Precision, Recall, F1-score, ROC-AUC).  Logistic Regression was chosen for its interpretability, despite tree-based models showing slightly better recall. The best model was saved as `artifacts/model.joblib`.

Deployment utilized FastAPI (`main.py`) with an API endpoint `/predict` to receive and process patient data.  The service was containerized using Docker and uvicorn. A static HTML form (`static/index.html`) provides a user interface for interaction, linking to additional reports (`EDA_Profile_Report.html`, `model_reports.html`), which themselves include `feature_importance.html` and `shap_force_plot.html`.  The project leverages a range of libraries including pandas, numpy, matplotlib, seaborn, plotly, ydata-profiling, scikit-learn, xgboost, lightgbm, shap, lime, FastAPI, Pydantic, joblib, Docker, and uvicorn (with optional mlflow integration).  The final report (`Report.md`) summarizes the entire workflow and key findings.  Multiple versions of `shap_force_plot.html` appear in the log, suggesting iterative updates during development.  The `feature_importance.html` file also shows multiple versions, indicating refinement of the feature importance visualization over time.
