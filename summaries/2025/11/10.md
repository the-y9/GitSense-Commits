**Patterns and Recurring Elements:**

1.  **Component-Based Architecture**: The project heavily relies on React components (`SideBar`, `DataListCard`, `GenericLineChart`, `GenericPieChart`, `GenericStatsCards`, `Dropdown`, `GenericTable`, `NavSidebar`).
2.  **State Management**: `useState` and `useMemo` hooks are consistently used across pages (`Dashboard`, `CurrentStock`, `StockIn`, `StockOut`, `Products`) for local component state and memoized computations to optimize performance.
3.  **Data Context**: The `useStockData` custom hook (from `StockDataContext`) is a central point for accessing and refetching stock-related data (`stockData`, `loading`, `fetchData`, `lastFetched`), promoting a global data store and avoiding prop drilling.
4.  **UI Consistency with Tailwind CSS**: All components use Tailwind CSS classes for styling, indicating a consistent design system (`bg-gray-50`, `text-gray-700`, `rounded-lg`, `shadow`, `flex`, `grid`, etc.).
5.  **Search and Sort Functionality**:
    *   `searchTerm`, `sortBy`, `sortOrder` states are present in `CurrentStock`, `StockIn`, `StockOut`, and `Products` pages.
    *   A `handleSort` function is consistently implemented to toggle sort order or set new sort fields.
    *   Search input with a `Search` icon from `lucide-react` is common.
    *   The data processing (`processedStock`, `processedStockIn`, `processedStockOut`, `processedProducts`) consistently includes filtering by `searchTerm` and sorting based on `sortBy` and `sortOrder`.
6.  **Loading State Handling**: Each data-intensive page (`Dashboard`, `CurrentStock`, `StockIn`, `StockOut`, `Products`) explicitly checks for `loading` state from `useStockData` and renders a "Loading data..." message.
7.  **Data Processing with `useMemo`**: Complex data transformations (e.g., merging stock in/out, grouping for charts, filtering/sorting tables) are wrapped in `useMemo` to prevent unnecessary re-calculations on every render, improving performance.
8.  **Sidebar Integration**: All main pages (`Dashboard`, `CurrentStock`, `StockIn`, `StockOut`, `Products`) integrate the `SideBar` component, customizing its title, navigation (`NavSidebar`), and footer. The `lastFetched` timestamp and a "Refresh" button are consistently placed in the `additionalComponentUp` prop of the `SideBar`.
9.  **Date Formatting**: Dates are consistently formatted using `toLocaleDateString` for user-friendly display (e.g., "November 10, 2025").
10. **Navigation with `react-router-dom`**: The `App.js` file and `NavSidebar.jsx` demonstrate the use of `BrowserRouter`, `Routes`, `Route`, `Link`, and `useLocation` for client-side routing. Active navigation links are highlighted.
11. **Robust Data Handling**: Several sections include checks for `Array.isArray()` and default values (`|| 0`, `|| "Other"`) when processing data from `stockData` to prevent errors from undefined or non-array data.
12. **Modularization**: There's a clear trend towards breaking down complex UI into smaller, reusable components (e.g., `GenericTable`).
