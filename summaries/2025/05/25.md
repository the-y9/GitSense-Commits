# Activity Summary for 5/25/2025

## 12:31:54 AM
The log shows iterative development of a Python script (`pdf_answering.py`) designed to answer questions based on the content of PDF documents.  The script utilizes the `transformers` library for text-to-text generation and a custom `pdf_faiss` library for efficient search within the PDF data.

Initially, the script used the `t5-small` model for question answering, with the prompt directly concatenating the question and extracted context.  The maximum length of the generated answer was adjusted from 200 to 300 tokens during early iterations.  Debugging print statements were added and removed in the process.

Significant changes involved refining the prompt structure.  It evolved from a simple concatenation to a more structured format that clearly separated the question and context, explicitly instructing the model to use the provided context for generating an accurate answer and including a default response ("Info not found.") if the answer is not in the context.  The model was later changed to `t5-base` and subsequently to `google/flan-t5-small` and `allenai/unifiedqa-t5-small` for potentially improved performance.  The word count in the prompt was also limited to 100 words at one point.

The input method changed from interactive user input to processing a pre-defined list of queries: "What are audit requirements?", "What are Penalties for Non-Compliance?", and "What is Reporting?", which was later expanded to include more complex, business-related questions about various company policies (e.g., inventory management, environmental sustainability, supplier selection, etc.).


The output presentation changed slightly, showing the source documents used for the answer. The detailed extraction of source information from the search results was eventually commented out for brevity.

A separate file, `pdf_chunk.py`, was introduced at the end of the log. This script handles the extraction and chunking of text from PDF files using PyMuPDF, identifying potential headings based on title case to better organize the document content for the question-answering process.  This function is used to generate the `results` that are passed to `pdf_answering.py`.
