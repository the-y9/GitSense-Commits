# Activity Summary for 5/26/2025

## 11:14:05 PM
The `api_models.py` file underwent significant changes between 10:14 PM and 10:38 PM on May 26, 2025.  Initially, it only contained a `BASE_URL` variable which was defined and updated with a AWS Lambda URL.  Subsequently, the code evolved to include imports for `dotenv`, `pydantic`, `requests`, `os`, and `json`.  The purpose of the code became evident: to send API requests to the specified BASE_URL.

The code incorporates error handling for a missing `API_KEY` environment variable, fetched using `os.getenv()`. The `API_KEY` itself changed multiple times in the `.env` file.

A `payload` dictionary was created to construct the API request, containing  `api_key`, `prompt`, `model_id`, and `model_params`.  The `model_id` was initially a placeholder, then set to `"model-id-here"`, and finally, was set to either  `"claude-3-5-sonnet"` or `'claude-3-haiku'`  depending on variable `small` or `medium` selection.  The `prompt` also started as a placeholder and finally changed to  "''' my clos are type, shipping day. give sql command for; Show unique types '''".

The code uses `requests.post` to send a JSON payload to the BASE_URL and processes the JSON response.  Initially, the code printed the entire response, but later it was refined to only print a specific part of the response – `"result["response"]["content"][0]["text"]"` –  and eventually this printing was commented out completely.  Variables `small`, `medium` and `emb` were introduced, setting model id strings that seem to relate to different model types.  The final version of the code at 10:38 PM sends a request with a SQL query as a prompt.
